# Support

Looking for help with xgoose? Here's where to look first.

## End users (chrome / firefox / safari)

- **How does it work?** → [xgoose.org/docs/](https://xgoose.org/docs/)
- **Skills directory** → [xgoose.org/skills/](https://xgoose.org/skills/)
- **Account / sign-in trouble** → email <support@xgoose.org>
- **Something broken in the chat panel** → open an issue on the
  extension's repo
  ([chrome](https://github.com/xGoose-dev/xgoose-extension-chrome/issues),
  [firefox](https://github.com/xGoose-dev/xgoose-extension-firefox/issues),
  [safari](https://github.com/xGoose-dev/xgoose-extension-safari/issues))

## Skill authors

- **Skill format reference** →
  [xgoose.org/docs/skills/](https://xgoose.org/docs/skills/)
- **Publishing a skill** → [xgoose.org/publish/](https://xgoose.org/publish/)
- **Bug in a built-in skill** → open an issue on
  [`xgoose-skills`](https://github.com/xGoose-dev/xgoose-skills/issues)

## Security issues

Do **not** open a public issue. See [SECURITY.md](./SECURITY.md).

## Anything else

Email <dev@xgoose.org>.
